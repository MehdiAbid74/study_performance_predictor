# Study Performance Predictor

Dieses Projekt untersucht, wie Lernzeit und Schlafdauer die Studienleistung beeinflussen.  
Es kombiniert Datenanalyse, Visualisierung und ein einfaches Machine-Learning-Modell.

## Features
- Analyse von Lernzeit und Schlafdauer
- Visualisierung von Zusammenhängen mit matplotlib
- Lineare Regression mit scikit-learn
- Berechnung des Fehlers (RMSE) und Modellbewertung

## Technologien
Python 3, pandas, matplotlib, scikit-learn
